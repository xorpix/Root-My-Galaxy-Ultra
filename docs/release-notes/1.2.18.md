## What's new

- Hotfix for the rebuilt module in 1.2.17: the reworked module-name filter stopped removing hidden entries from `/proc/modules` for readers that can see the file at all (verified on-device; on the affected device that was a root shell). The filter now arms exactly the way the 1.2.16 module did, which hid those entries from every reader. Every other hiding and spoofing feature of the 1.2.17 module, including `/proc/kallsyms` name filtering, is unchanged and was verified working on the same test pass.
- The regression was not visible in app-side status checks because Android SELinux policy denies app access to `/proc/modules` entirely; it was found with on-device root-shell testing. Module import verification and the host test suites stayed green both in 1.2.17 and here, so this release adds a plain root-reader check to the module acceptance steps.

## Validation

Settings and unit tests, backend bundle checks, embedded companion verification, module import verification (the 1.2.18 module keeps the exact same import surface as 1.2.16 and 1.2.17) and host runner suites gate publication. A full on-device activation pass for this module is still pending; SusFS LKM remains experimental.

## Updating

1. Install **RootMyGalaxyUltra-1.2.18.apk** over the existing app; it uses the same package and release signing key.
2. If SusFS was activated with 1.2.16 or 1.2.17, perform a **full reboot** first, then re-run SusFS activation so the fixed module is loaded.

The bundled backends and boot helper are unchanged from 1.2.15. The boot helper does not need reinstalling for this update.
