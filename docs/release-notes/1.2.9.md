## What's new

### Samsung soft reboot fix

- Extended the Samsung composer fix to **Soft reboot started directly from KernelSU, KernelSU-Next and BakaSU managers**.
- The bundled daemons now install shared lifecycle hooks when RMGU activates root. The hooks run before Android's framework restarts, so replacing the installed daemon or updating the manager does not remove this fix.
- Kept RMGU's bundled-daemon fallback and added transition tracking to avoid restarting the composer twice.
- Ordinary root activation and full boots do not trigger a composer restart. The shared hook skips an expired or unsafe restart window.

Rebuilt all three matched backend pairs with the shared Samsung composer hooks, using the same upstream revisions as 1.2.8. Each bundled daemon embeds its matching driver. All three use **UAPI 5**.

## Validation and current limits

- Checks cover the three native backend builds, Android unit tests, driver/daemon matching, APK payload integrity and release signatures. Host tests cover manager-triggered transitions, repeated reboots, stale state, interrupted resets and the native fallback.
- **Samsung DeX recovery after a manager-triggered soft reboot still needs confirmation on a phone.** Automated checks do not establish device coverage.
- Shared hooks follow the manager daemon's lifecycle support and safe-mode rules. If module scripts use up the restart window, the common hook skips the reset; RMGU's bundled native fallback remains available.
- The upstream KernelSU-Next branch has rewritten its history. Automatic upstream tracking pauses until its source pin is reviewed; this release rebuilds the exact revision already used in 1.2.8.
- SusFS LKM remains experimental. Duck Detector's cross-process mount-view warning is not confirmed resolved; installed-app/package-list detections are a separate layer.

## Updating

1. Install **RootMyGalaxyUltra-1.2.9.apk** over the existing app; it uses the same package and release signing key.
2. Perform a **full reboot**, then activate root again through Root My Galaxy Ultra. This installs the shared hooks and loads the updated backend; installing the APK alone is not enough.
3. Test **Soft reboot** from your root manager, then check Samsung DeX. RMGU's own Soft reboot action remains available.

Use a **UAPI 5-compatible manager** for your selected backend. Updating the manager alone does not replace the loaded driver.
