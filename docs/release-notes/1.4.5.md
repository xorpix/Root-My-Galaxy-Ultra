# Root My Galaxy Ultra 1.4.5

- Refreshed the bundled root backends and compatible manager links.
- Fixed the daily compatibility failure after KowSU rebased its upstream history.
- Updated Samsung compatibility patches for BakaSU’s reorganized SELinux code.
- Pinned the Bouncy Castle utility dependency to make APK builds more reproducible.
- Improved SusFS path matching so a reused inode number does not apply an old hiding rule to a replacement file.
- Fixed SusFS handling of Rust module symbol types found on Android 16 GKI kernels.
