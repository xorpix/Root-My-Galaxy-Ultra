## What's new

- **Faster root on boot.** Removes the inherited 60-second wait before unlock and for automatic DirtyFrag runs after unlock. Root readiness finishes as soon as success is confirmed.
- **Recovery after firmware updates.** A successful manual root run refreshes the cached backend and existing early-root setup. Missing or damaged cached files can be replaced without reinstalling the app.
- **More reliable boot automation.** Keeps boot state consistent between the app and boot workers, preserves retry requests, and ignores duplicate boot events without stopping an active run.

The fast-boot test build was confirmed working on the maintainer's S26 Ultra. Firmware-update cache recovery is covered by automated regression tests.

## Updating

1. Install **RootMyGalaxyUltra-1.4.1.apk** over the existing app to keep your settings.
2. Open the app once, then perform a **full reboot** to test automatic root.

If a cached backend was already rejected after a firmware update, complete one manual root run and fully reboot again to use the renewed automatic setup.
