### BZJA support confirmed

Root and SusFS have been confirmed working on **S948BXXU5BZJA**. Users have also
reported success on other Galaxy S26 Ultra models. The app continues to select
the matching backend for your phone automatically.

### A cleaner SusFS screen

- Removed the **experimental** label and the outdated **untested kernel** message.
- Made the status easier to read: normal text contrast, with the version below
  the heading instead of squeezed beside a long description.
- Simplified the switch description and removed the extra confirmation when
  turning SusFS off. The status still shows when it remains active until reboot.
- Removed the extra installation confirmation and testing text from bundled
  payload descriptions. Updated the same SusFS text across all app languages.

This release uses the same verified backend and SusFS module payloads as 1.2.28.
Activation, integrity and compatibility checks remain in place.

### Updating

Install **RootMyGalaxyUltra-1.3.0.apk** over your current app. Your settings are
kept. The native modules are unchanged, so this update does not require a full
reboot just to replace them.

After a normal full reboot, root and SusFS must be activated again, either
automatically with your configured boot options or through the app. Firmware
updates can change compatibility; successful tests do not guarantee support for
future security patches.
