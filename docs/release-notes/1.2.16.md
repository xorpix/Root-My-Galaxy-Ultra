## What's new

- Settings now follow the current firmware and root method. AZHL shows its applicable manual delay and run limits; DirtyFrag shows only the controls it uses.
- Run plan shows the selected backend, bundled payload source and required transport. Manual profile choices stay within the selected backend, and profiles for another firmware are marked unavailable.
- Clarified AZHL's Shizuku requirement and replaced its unsupported "run without Shizuku" action with cancellation. Wireless debugging descriptions now explain when pairing is optional.
- Manual delay choices reflect the existing minimum, and the displayed value matches the saved preference.
- Reset labels and confirmations explain the scope for each root method. Removed the unavailable Reload modules action.
- SusFS status now shows when the module remains active until reboot after automatic activation is turned off. Existing activation preferences can still be turned off on incompatible firmware.
- Clarified mandatory backend loading and the automatic boot-delay description.

## Validation

Settings presentation tests, Android unit tests, backend bundle checks, embedded companion verification, APK integrity and release-signature checks gate publication. Device testing remains pending; SusFS LKM remains experimental.

## Updating

1. Install **RootMyGalaxyUltra-1.2.16.apk** over the existing app; it uses the same package and release signing key.
2. If upgrading from 1.2.14 or earlier, perform a **full reboot** to load the refreshed backends introduced in 1.2.15.

The bundled backends, SusFS module and boot helper are unchanged from 1.2.15. The boot helper does not need reinstalling for this update.
