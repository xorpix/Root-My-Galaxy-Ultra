## What's new

- Faster automatic DirtyFrag rooting during locked boot. The trigger observes its adoption by init and can finish as soon as that condition is met, replacing the fixed one-second wait.
- Root readiness checks can accept a completed, pre-authorized UID 0 result immediately. The bounded fallback, native cleanup and final backend verification remain in place.
- Removed temporary boot-timing collection and elapsed-time logging after acceptance testing.

## Updating

1. Install **RootMyGalaxyUltra-1.2.14.apk** over the existing app or boot-speed candidate; it uses the same package and signing key.
2. Perform a **full reboot** to exercise the updated automatic root path.
3. Keep the existing boot helper; this update does not require its replacement.
