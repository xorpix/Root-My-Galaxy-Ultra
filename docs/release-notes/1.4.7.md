# Root My Galaxy Ultra 1.4.7

- Fixed automatic SusFS app selection failing when the root shell could not see other apps' data directories.
- Expanded automatic selection for root and Shizuku companion apps, including Ice Box.
- Kept refreshes on existing app and package events, with bounded root commands.

All four official backend source branches were rechecked on 26 November 2026. The verified driver and daemon pairs are current and unchanged from 1.4.6.

Install over the existing app. From 1.4.6 or the namespace test APK, open RMGU with root and SusFS active and allow about 20 seconds for the app list to refresh. This update does not require a reboot. When upgrading from an older release, fully reboot before activating root and SusFS to replace the older loaded backends.

The namespace fix was tested on the maintainer's phone and removed all seven previously reported UID mismatches. The final Ice Box addition passes automated selection tests; its phone result still needs confirmation. Host, native, Android, bundle-integrity and release-signature checks gate publication.
