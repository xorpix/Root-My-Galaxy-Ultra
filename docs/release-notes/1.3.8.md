## What's new

- **Fixes SusFS startup on affected Samsung kernels.** Uses the tested Open Redirect fallback when the kernel refuses the original syscall-table writes. Temporary troubleshooting output is removed.
- **SusFS across S26 Ultra regions.** Removes the per-firmware profile allowlist and uses one verified shared bundle, including for SM-S948N. ARM64, 4 KB pages and the Android 16 / Linux 6.12 kernel family are still checked; success requires the live SusFS API to answer correctly.
- **Recovery helpers clean up after themselves.** Soft reboot, module reload, framework restart and reboot helpers remove their own scripts, logs and acknowledgement files after completion, including when their caller has gone away. Failure details remain available to the caller before cleanup.

The Open Redirect fix candidate was confirmed on the maintainer's S26 Ultra. The regional-model change permits activation attempts on matching kernels; individual regional kernels have not all been tested. Mountify remains unsupported.
