## What's new

- **Fixes SusFS startup on affected Samsung kernels.** Root could succeed while SusFS reported that Open Redirect was unavailable. The fallback now starts the redirect entries when the kernel refuses the original syscall-table writes.
- **Removes temporary troubleshooting output.** The startup diagnostics used to find and verify the fix are removed from the production app and module.

The fix candidate was confirmed working on the maintainer's S26 Ultra. The production build keeps the same fallback behavior and removes its temporary diagnostics. Automated checks cover startup failures, cleanup, native/compat calls, callback lifetime, Android tests, bundled payloads and signing. No separate phone test of the stripped production binary or redirect-rule execution is claimed.

## Updating

1. Install **RootMyGalaxyUltra-1.3.8.apk** over the existing app.
2. Perform a **full reboot**.
3. Activate root again and enable SusFS.
