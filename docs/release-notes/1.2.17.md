## What's new

- The bundled SusFS module was rebuilt from the upstream sync: fix checkpoints from the SusFS upstream tree through October 2026 were ported onto the Samsung implementation, including the LSM large-hook identification no longer relying on build-time offsets and the SELinux hook acceptance fix.
- Hidden paths, kstat spoofing and map hiding now follow KernelSU's own answer for which apps modules are hidden from: a profile with root granted, the manager, and profiles with "umount modules" disabled are no longer subject to hiding, matching SusFS upstream behavior (previously every app UID was treated the same). Ordinary-app hiding is unchanged.
- Module symbol hiding re-arms its /proc filters from the actual callback tables and falls back to the previously validated method when a table cannot be verified, instead of guessing by CONFIG.

## Validation

Settings and unit tests, backend bundle checks, embedded companion verification, module import verification (the new module keeps the exact same import surface as 1.2.16) and host runner suites gate publication. A full on-device activation pass for the rebuilt module is still pending; SusFS LKM remains experimental.

## Updating

1. Install **RootMyGalaxyUltra-1.2.17.apk** over the existing app; it uses the same package and release signing key.
2. If SusFS was activated in 1.2.16 or earlier, perform a **full reboot** first, then re-run SusFS activation so the rebuilt module is loaded.

The bundled backends and boot helper are unchanged from 1.2.15. The boot helper does not need reinstalling for this update.
