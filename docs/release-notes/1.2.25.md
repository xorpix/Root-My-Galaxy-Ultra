## What's new

- **KowSU is now a fourth backend**, alongside KernelSU, KernelSU-Next and
  BakaSU. It is available in the backend selector, manager detection, AZHL/M3Q
  installation and DirtyFrag profiles, including eligible S26 Ultra regional
  profiles. Backend descriptions are updated in all eleven translations.
- **A matched KowSU driver and daemon** are bundled from the pinned official
  source below, with RMGU's Samsung KDP/RKP/DEFEX and soft-reboot compatibility
  changes. KowSU keeps its upstream UAPI, version formula and manager signer.
  Its native helpers and bridge select the KowSU manager package correctly.
- **Daily compatibility checks and weekly backend releases cover all four
  backends.** Manager artifact verification, build provenance, release staging
  and bundle checks include KowSU. Version updates now identify each backend
  explicitly, so overlapping KernelSU and KowSU version numbers cannot change
  the wrong backend. The standalone release workflow uses the matching JDK 25
  and NDK r28c toolchains.

  existing three backend payloads and SusFS payload are unchanged from 1.2.24.

## Updating

1. Install **RootMyGalaxyUltra-1.2.25.apk** over the existing app; it uses the
   same package and release signing key.
2. To switch to KowSU, perform a **full reboot**, then select KowSU and activate
   root in RMGU. A soft reboot keeps the previously loaded backend in memory.
3. Install the matching KowSU manager and verify root and your modules there.
   Use a manager compatible with the selected backend's UAPI.

The existing boot helper does not need reinstalling for this update.
