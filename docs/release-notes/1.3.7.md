## Validation and scope

The SusFS change passed the production host regressions, sanitizer controls and negative controls. Native compilation checks its imports, callback ABI and all 22 syscall-wrapper landing instructions. The release also checks Android tests, matched driver/daemon payloads, APK contents, the embedded D2 helper and the existing release signature.

The changed SusFS binary and refreshed backend revisions have not had a new phone test during this update. The BTI fix is defensive stability work; no matching crash was demonstrated on the maintainer's current firmware. Firmware support remains the existing BZIG, BZID and BZJA profiles.

## Updating

1. Install **RootMyGalaxyUltra-1.3.7.apk** over the existing app.
2. Perform a **full reboot** to replace the loaded backend and SusFS module.
3. Activate root again and enable SusFS.

Use a manager matching the UAPI shown above. Verified downloads are in the [README](https://github.com/xorpix/Root-My-Galaxy-Ultra#backends-and-manager-apps).
