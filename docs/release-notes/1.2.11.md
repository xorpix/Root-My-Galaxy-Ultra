## What’s new

### Root before first unlock

- Added optional **Root before first unlock** under **Root Management**. It
  restores root at the first PIN/password screen using the activated boot helper
  and a previously verified bundled DirtyFrag setup. It is off by default and
  requires **Root on boot**.
- Configured **SusFS** activation and **Auto Soft reboot** can now finish the
  root setup before first unlock, using saved boot settings and the app's existing
  superuser grant.
- Starts root after the first verified Odin observation while the remaining Odin
  checks continue. The planned module restart waits for those checks to finish.
- Shortens the early worker's post-trigger wait when a completed superuser command
  confirms readiness, retaining the original fallback, native cleanup and final
  backend verification.
- Bounds startup root probes so a stalled superuser command cannot hold boot work
  indefinitely. Timed-out or incomplete commands do not count as root proof.
- Keeps verified boot results and separate SusFS/restart status. Durable boot
  claims prevent duplicate root attempts and automatic restart loops. Temporary
  test timing traces and profiling callbacks have been removed.

### Bundled components

The boot helper is now **version 5**. All three backends are rebuilt as matched
driver/daemon pairs from pinned official sources with the Samsung compatibility
changes. KernelSU now requires a **UAPI 6** manager; KernelSU-Next and BakaSU
require **UAPI 5** managers. The separate SusFS module is unchanged.

## Validation and limits

- The maintainer confirmed root, SusFS activation and a soft restart into a rooted
  state at the first PIN screen on **SM-S948B / S948BXXS4BZIG with BakaSU**. The
  faster build verified root at about **54 seconds after boot**, roughly eight
  seconds earlier than the preceding test build on that phone. Other recognized
  variants and boot timings are not established by this result.
- Release validation covers boot scheduling and fallback behavior, bounded root
  commands, Android unit tests, embedded helper identity/signature, APK payload
  integrity and production signing.
- The faster before-unlock path was tested before this backend refresh. Build
  checks for the refreshed pairs do not establish new hardware test results.
- Root remains temporary. A failed root attempt needs a full reboot before
  retrying. SusFS remains experimental; verify your manager and actual modules
  after any automatic restart.

## Updating

1. Install **RootMyGalaxyUltra-1.2.11.apk** over the existing app and open it once.
2. Under **Recovery Management → Keep Odin reachable**, choose **Update helper**
   when offered to install **version 5**, then **fully reboot**. Activate it if
   asked. Existing certificate preparation does not need repeating. Users already
   on test6 with helper version 5 do not need another helper update.
3. Establish a successful manual root run with your selected bundled DirtyFrag
   backend if requested, and grant RMGU superuser access in its manager.
4. Enable **Root on boot**, then **Root before first unlock**. Keep your desired
   boot delay, SusFS and Auto Soft reboot choices, then fully reboot.

**Root on boot** is the master switch for automatic rooting. **Keep Odin reachable**
remains independent. Ordinary manual rooting does not require the helper.

See the [before-unlock setup guide](https://github.com/xorpix/Root-My-Galaxy-Ultra/blob/main/docs/root-before-unlock.md)
for requirements, results and recovery steps.
