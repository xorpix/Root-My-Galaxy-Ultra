## What's new

### Samsung soft reboot fix

- Fixed RMGU's **Soft reboot** action using an unpatched daemon after a KernelSU manager replaces `/data/adb/ksud`, which could still leave Samsung DeX broken despite the composer fix in 1.2.7.
- RMGU now prefers its bundled Samsung-patched daemon for the backend loaded in the current kernel boot, after checking that it reports the expected running driver version.
- Capability detection and soft reboot use the same selected daemon. The installed-daemon fallback is retained for unknown, unavailable or mismatched backends.
- Integrated [PR #13](https://github.com/xorpix/Root-My-Galaxy-Ultra/pull/13), with thanks to [@Anajrim01](https://github.com/Anajrim01) for identifying the overwritten daemon and testing the fix.

## Validation and current limits

- Release checks cover Android unit tests, driver/daemon matching, APK payload integrity and release signatures. Host bundle and preparation checks also passed.
- The PR author reported Samsung DeX working after one soft reboot through RMGU on a Galaxy S26 Ultra with this daemon-selection change. The published APK still needs confirmation on a phone.
- **Soft reboot directly from a KernelSU manager remains affected. Use RMGU's Soft reboot action for this fix.** RMGU does not replace the manager's installed daemon.
- SusFS LKM remains experimental. Duck Detector's cross-process mount-view warning is not confirmed resolved; installed-app/package-list detections are a separate layer.

## Updating

1. Install **RootMyGalaxyUltra-1.2.8.apk** over the existing app; it uses the same package and release signing key.
2. Perform a **full reboot**, then activate root again through Root My Galaxy Ultra. A soft reboot keeps the existing kernel modules loaded.
3. When a soft reboot is needed, start it from **Root My Galaxy Ultra** to use the bundled Samsung-patched daemon.

Use a **UAPI 5-compatible manager** for your selected backend. Updating the manager alone does not replace the loaded driver.
