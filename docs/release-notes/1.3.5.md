## What's new

- **Updated KernelSU and KernelSU-Next.** The bundled drivers and daemons are matched pairs built from the official source revisions below. The README includes verified compatible manager downloads.
- **NoMount hiding with installer compatibility.** SusFS now includes NoMount in its configured module filter. Non-root readers get the hiding policy, while root keeps the module listing and control access that NoMount's installer needs.
- **Safer SusFS module-list activation.** SusFS verifies the callback before enabling its module-list filter and bounds reads of module names. This preserves the filtering behavior confirmed on the maintainer's Samsung device.

## Validation and scope

- The SusFS changes passed 66 host test runs, sanitizer controls, native ABI checks and Android packaging checks. Phone checks confirmed that NoMount's sysfs entry is hidden from a non-root app UID, remains accessible to root, and NoMount still works. Android denied the non-root `/proc/modules` read, so that specific view was not verified on the phone. See the [phone-test record](https://github.com/xorpix/Root-My-Galaxy-Ultra/blob/main/docs/susfs-nomount-hiding-20261108/phone-validation.json).
- The refreshed backend revisions passed their native build, driver/daemon matching and app checks. They have not had a separate phone test. SusFS retains its exact BZIG, BZID and BZJA firmware/kernel checks.
- The production release workflow checks Android tests, bundled payloads, the D2 companion, the release signature and APK alignment. `SHA256SUMS` accompanies the APK.

## Updating

1. Install **RootMyGalaxyUltra-1.3.5.apk** over the existing app.
2. Perform a **full reboot** to replace the loaded backend and SusFS module. A framework restart does not replace loaded kernel modules.
3. Activate root again and enable SusFS in the updated app.

Use a manager compatible with your selected backend's **UAPI 6**. Verified download links are in the [README](https://github.com/xorpix/Root-My-Galaxy-Ultra#backends-and-manager-apps).
