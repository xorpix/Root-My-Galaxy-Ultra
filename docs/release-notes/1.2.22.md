## What's new

- **Streamlined installation across the S26 Ultra family.** Regional and carrier
  variants, including /DS and Japanese models, use the same family-wide flow.
  Choose a backend once; Install opens the installer directly for automatic or
  matching bundled selections. This includes the AZHL firmware route.
- Removed the repeated experimental-build confirmation and shortened the backend
  chooser text in every supported language. Required choices, permissions,
  mismatch warnings, reboot prompts and destructive-action confirmations remain.
- Completed translation coverage for current app features across all eleven
  translated languages. Rewrote the Russian catalog and corrected contextual
  errors, terminology and controls in the other supported translations.

## Validation

- Android resource compilation, the full app unit suite and translation checks
  passed. Presentation tests cover the full accepted regional suffix pattern,
  Japanese carrier models, all three backends, AZHL and mismatched selections.
- The release build verifies the production signing key, APK alignment, embedded
  companion and bundled-file integrity before publishing.
- Device eligibility and runtime verification are unchanged. Backend, daemon and
  SusFS payloads are unchanged from 1.2.21.

## Updating

Install **RootMyGalaxyUltra-1.2.22.apk** over the existing app. It uses the same
package and release signing key.

When updating from 1.2.21, this release does not replace the loaded backend or
SusFS module. When updating from an older version, perform a full reboot to load
the newer bundled kernel components on your next root session.
