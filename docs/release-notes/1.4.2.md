# Root My Galaxy Ultra 1.4.2

- Updated the bundled KernelSU, KernelSU Next, BakaSU and KowSU backends.
- Fixed backend refresh compatibility with the latest KernelSU changes, including Samsung handling for the new SELinux hook.
- Keeps the faster root-on-boot startup and cache recovery improvements from 1.4.1.
- Reviewed the latest SusFS LKM changes. The existing Samsung module already includes the relevant counter fix and retains its tested hiding and Open Redirect behavior.
