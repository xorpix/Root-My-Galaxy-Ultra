## What's new

One module fix (upstream PR #114, integrated hunk-for-hunk):

- **A reused kprobe can no longer register successfully but stay disarmed.** Unregistering a kernel probe leaves `KPROBE_FLAG_DISABLED` set on its struct, and the kernel's `register_kprobe()` preserves that bit — so a struct handed back for reuse after a disable/re-enable or a retry after a failed registration could re-register with a clean return value yet never arm, leaving a feature silently off. The module's shared struct-reuse helpers now clear the disabled bit together with the resolved address before every re-registration; unrelated flag bits and the symbol name are kept intact. The change is confined to an inline header, so no import is added and the compiled module keeps exactly the 1.2.19 size.

The 1.2.19 maintenance sync (bootconfig spoof reclamation, zeroed `uname` tails, `GKI-LKM` variant), the 1.2.18 `/proc/modules` filter fix and the mount implementation are unchanged.

## Validation

Module imports are unchanged from every published module since 1.2.16 (the 135-symbol strong import surface is identical, nothing added or removed). Module size is 498,272 bytes stripped, equal to 1.2.19 (sha256 is pinned per profile). The full host suite passes across all 20 runners in both plain and sanitizer modes, including the new `kprobe_reuse` runner, which compiles the actual production header against a model of the native registration rule: eight positive cases (kprobe and kretprobe reuse cycles, failed-lookup retry, unrelated-flag preservation, idempotence) and six negative controls that remove the fix and must fail.

A full on-device activation for this module is still pending; **SusFS LKM remains experimental** until one activation passes on a BZIG device.

## Updating

1. Install **RootMyGalaxyUltra-1.2.20.apk** over the existing app; it uses the same package and release signing key.
2. If SusFS was activated with an earlier release, perform a **full reboot** first, then re-run SusFS activation so the updated module is loaded.

The bundled backends and boot helper are unchanged from 1.2.15. The boot helper does not need reinstalling for this update.
