## What's new

- **SusFS lock fix.** Reading module status now takes locks in the same order as configuration updates. This fixes a potential kernel deadlock when those operations run at the same time.
- Module hiding and NoMount compatibility retain the behavior of 1.3.5. Bundled backends are unchanged.

## Validation

The maintainer confirmed the signed hotfix candidate works on the phone. This release keeps the exact tested SusFS module. All 66 host test runs, native ABI checks, Android tests and signed-candidate packaging checks passed. No temporary diagnostic logging is included.

## Updating

1. Install **RootMyGalaxyUltra-1.3.6.apk** over the existing app.
2. Perform a **full reboot**, then activate root and enable SusFS again.
