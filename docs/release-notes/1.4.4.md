# Root My Galaxy Ultra 1.4.4

- Fixed how the app handles an unclear SusFS status. It now skips another load attempt and shows "Couldn't determine SusFS status" in Settings.
- Hardened SusFS bundle checks so changed or incorrectly packaged files are still rejected when Python optimization is enabled.
- Refreshed the bundled KernelSU driver and daemon to the latest upstream revision. KernelSU-Next, BakaSU and KowSU are already current.
