## What’s new

RMGU now checks that system logging is enabled before starting DirtyFrag. This prevents a root attempt from failing because **Logger buffer sizes** is set to **Off**.

- When **Use Shizuku** is enabled and Shizuku is already running and authorized, RMGU can re-enable logging automatically and verify the change.
- If automatic repair is unavailable or cannot be verified, RMGU stops before patching anything and explains how to select **Developer options → Logger buffer sizes → 4M**, then retry.
- The instructions are available in every supported language.

## Updating

Install **RootMyGalaxyUltra-1.3.2.apk** over your current RMGU installation. It uses the same package and release signing key.
