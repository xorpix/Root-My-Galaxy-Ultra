## What's new

### Automatic SusFS app protection

SusFS now automatically protects **RMGU, your root manager and apps granted root**
from detection through scheduling-priority queries. Renamed managers are recognized
too, and changes to root permissions take effect automatically.

There is no package list to set up. The feature works alongside HMA OSS; keep
RMGU outside HMA's filtered-caller scope so it can discover installed managers.
The maintainer completed device testing and reported no HMA failures.

### Refreshed backends

Updated KernelSU, KernelSU-Next, BakaSU and KowSU as matched driver/daemon pairs,
with compatible manager download links. Temporary test probes and diagnostics
have been removed for the production build.

### Updating

Install **RootMyGalaxyUltra-1.3.1.apk** over your current app; your settings are kept.
Then **fully reboot**, obtain root and enable SusFS. A soft restart keeps the old
kernel modules loaded and cannot apply this update.
