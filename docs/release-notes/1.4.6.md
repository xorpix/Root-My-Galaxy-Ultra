# Root My Galaxy Ultra 1.4.6

- Improved SusFS selection for Shizuku and Galaxy Max Hz when they run through ADB or Shizuku without their own root grant.
- Refresh installed helpers from a current root package list so app-list filtering on RMGU does not omit them. The refresh uses existing events and one bounded retry.
- Updated KernelSU, KernelSU-Next and BakaSU, with verified matching drivers, daemons and compatible manager links.
- Included upstream module-ID validation fixes, reduced repeated backend extraction at boot and a BakaSU SELinux context fix.
