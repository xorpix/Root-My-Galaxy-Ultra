## What's new

### Optional Samsung D2 fix

- Added **D2 fix · Keep Odin reachable** under Advanced settings → Recovery, based on the DFReroot/Root My Galaxy Next DMC workaround.
- The separate signed helper reapplies Samsung's AT flag at boot with the screen lock enabled. After the one-time root setup, it works independently of autoroot. The switch is off by default.
- Added bounded boot retries, strict record validation and complete read-back verification. Status shows the observed flags and age, and rejects stale boot observations as current verification.
- Added embedded-helper installation, activation, updates and scoped removal, with verified registry backups during certificate preparation.
- Release builds verify the nested helper's signature and permissions. The weekly signing job also rebuilds and signs the helper with the production key.

### Bundled backends

The bundled backend pairs and SusFS module are unchanged from 1.2.9. All three backends use **UAPI 5**.

## Validation and current limits

- Automated tests cover vault byte preservation, unsupported layouts, cancellation, concurrent changes, uncertain writes and exact read-back, plus scoped package-signature preparation/cleanup.
- **D2 behavior and the privileged setup still need validation on the target phone.** A verified AT flag does not guarantee bootloader recovery. Very early boot failures and the reset/reapply interval remain uncovered.
- Preparation changes Android's package-signature trust and requires existing root followed by a prompt full reboot. Read the in-app confirmation and [setup guide](https://github.com/xorpix/Root-My-Galaxy-Ultra/blob/main/docs/d2-fix.md) before enabling it.
- Existing firmware, backend and SusFS limits still apply. This adds no new exploit or firmware support.

## Updating

1. Install the production APK over the existing app; it uses the same package and release signing key.
2. For D2, follow **Advanced settings → Recovery → D2 fix**: prepare the helper certificate with root, fully reboot, install the embedded helper, activate it and enable the switch.
3. Test a full boot with autoroot off and the screen lock enabled, then check the actual DMC reading before checking Download Mode access.

The helper is optional. Ordinary rooting does not require its installation.
