## What’s new

### Keep Odin reachable

- Added **Keep Odin reachable** under **Advanced settings → Recovery**. It helps keep Samsung Download Mode available when a screen lock is set.
- An optional, included **RMGU Odin Helper** runs automatically after one-time setup, independently of **Root on boot**. The feature is off by default.
- Simplified settings to a switch, a short automatic status and guided setup/update steps. Removed **Check status**, **Inspect setup**, raw flags, timestamps and diagnostic text.
- Setup actions appear only when needed. Once setup is finished, the activation button is hidden and the setting can be turned on or off directly.
- Includes verified settings persistence, reboot-safe helper communication and signed-helper updates. Automatic record validation and write verification remain in place.

### Bundled backends

The three matched backend pairs and SusFS module are unchanged from **1.2.9**. All three backends use **UAPI 5**; continue using a compatible manager for your selected backend.

## Validation and limits

- The maintainer confirmed successful full-reboot and Download Mode testing on **SM-S948B**. Other models and firmware versions still depend on Samsung’s implementation.
- Release checks cover Android unit tests, matched driver/daemon pairs, the embedded helper’s signature and permissions, APK payload integrity and production signing.
- This helps preserve Download Mode access after Android starts; it cannot cover every early boot failure. SusFS LKM remains experimental.

## Updating

1. Install **RootMyGalaxyUltra-1.2.10.apk** over the existing app.
2. Open **Advanced settings → Recovery → Keep Odin reachable**.
3. If you used a D2 test build, choose **Update helper** when offered and **restart your phone**. Choose **Finish setup** if prompted. Existing certificate preparation remains valid and does not need repeating.
4. For a first installation, follow the guided **Set up helper → restart → Install helper → restart → Finish setup** flow, then turn on the switch. Root is needed for the initial preparation; routine operation works without it.

See the [setup guide](https://github.com/xorpix/Root-My-Galaxy-Ultra/blob/main/docs/d2-fix.md) for details. The helper is optional; ordinary rooting works without installing it.
