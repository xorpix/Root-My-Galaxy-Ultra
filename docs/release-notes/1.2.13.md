## What's new

- Fixed hidden SusFS control files appearing in directory listings on Samsung kernels. Filtering now covers the directory syscall entries and omits hidden entries before the kernel writes them to the caller's buffer.
- Hidden paths now return ENOENT for O_PATH opens and readlink, with native lookup, error and retry behavior retained.
- Keep directory hiding tied to the original caller when a filesystem temporarily changes credentials, including control-file identity across procfs instances.
- Increased the configurable suspicious-mount prefix limit to 64.
- Removed temporary directory tracing, per-entry samples and test counters after successful phone testing.
- Refreshed changed backend drivers and their matching embedded daemons, including KernelSU-Next's filesystem-notification cleanup fix and BakaSU's dependency update.
- Fixed the weekly manager fixture for mixed UAPI versions and reviewed the exact BakaSU history transition required by the updater.

## Validation

The directory fix passed 200 phone listings without leaking the protected control, and O_PATH/readlink both returned ENOENT. Normal apps/modules, root before first unlock and soft restarts were also confirmed working on the tested phone. The release removes temporary instrumentation from that implementation.

Pinned kernel builds, host regression checks, matched driver/daemon checks, Android unit tests, APK integrity and release-signature checks gate publication. Newly refreshed backend revisions have automated build validation; device coverage remains specific to the configurations actually tested. SusFS LKM remains experimental.

## Updating

1. Install **RootMyGalaxyUltra-1.2.13.apk** over the existing app; it uses the same package and signing key.
2. Perform a **full reboot** to replace the loaded backend and SusFS modules. A soft restart retains loaded kernel modules.
3. Activate root again through Root My Galaxy Ultra and enable SusFS as usual.
