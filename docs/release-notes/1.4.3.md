# Root My Galaxy Ultra 1.4.3

- Fixed the error shown when the app could not verify root. The message now asks you to check the backend status and the app's superuser access in its manager. See [#60](https://github.com/xorpix/Root-My-Galaxy-Ultra/issues/60).
- Updated the bundled KernelSU, KernelSU-Next and BakaSU drivers and daemons. KowSU is already current.
