# Root My Galaxy Ultra 1.4.9

- Fixed the instant reboot (kernel panic) reported in issue #68 on One UI 9.5 beta S948BXXU6ZZKN, kernel 6.12.69: the DirtyFrag 6.12 kernel module was rebuilt from the current upstream DFRoot module (7a6513a, v4.7 plus the libbase hook fallback). The old module had no `module_exit`, so kernels whose `cfi_init` walks both the init and cleanup jump tables crashed in `strcmp` while the module loaded, right after the second page-cache patch.
- The rebuilt module also carries the newer upstream Samsung and SELinux handling the old module lacked: `avc_has_perm` patching when the `selinux_state` write is a no-op, direct DEFEX patching through `aarch64_insn_patch_text` instead of body-skipping kprobes, `crash_dump64` page-cache invalidation, and BTI/PAC-aware return stubs.
- All four per-backend bridges (KernelSU, KernelSU-Next, BakaSU, KowSU) and the generic 6.12 image were rebuilt from that module with the existing staged-daemon command and marker contract unchanged. Kernel modules, daemons and managers are unchanged from 1.4.8.
