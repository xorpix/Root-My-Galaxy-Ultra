## What's new

Module maintenance (upstream sync of 2026-10-21, reviewed and integrated):

- **Bootconfig spoof memory is reclaimed.** Previously every replaced bootconfig value was kept for the module's lifetime, because a native reader could still hold the replaced pointer. Replaced and reset values are now retired and freed after a Tasks RCU grace period covers the native `/proc/bootconfig` reader window (the same mechanism the module already uses elsewhere), so repeated rearm/reset cycles no longer accumulate module memory. Unload refuses new sets with the documented `-ENODEV` and, if an external owner holds a value the module could not restore, that value is retained rather than freed underneath it.
- **Spoofed `uname` strings no longer leak stale bytes.** Fixed-size kernel buffers for release/version keep bytes from longer previous values past the string terminator; the tails are now zeroed after module-parameter parsing and after every update, so the fields copied to userspace are exact.
- **The reported SusFS variant is now `GKI-LKM`** instead of `GKI`, inside the unchanged supercall ABI field. The app passes the variant through, so the status line will show the new label.

Reviewed for this fork and intentionally not taken: mount-ID batch scanning, an identity devname-lookup variant, the upstream `imports_guard`, the `ksu_allow_gate` control-node relabel, and an audit-log source-SID rewrite. The 1.2.18 `/proc/modules` filter fix, the mount implementation and the AVC code are unchanged.

## Validation

Module imports are unchanged from every published module since 1.2.16 (the 135-symbol strong import surface is identical, nothing added or removed). The full host suite passes across all 19 runners in both plain and sanitizer modes, including the updated identity-controls suite that now covers the reclamation path with allocation accounting, reader-window cases and new negative controls. Module size is 498,272 bytes stripped (sha256 is pinned per profile).

A full on-device activation for this module is still pending; **SusFS LKM remains experimental** until one activation passes on a BZIG device.

## Updating

1. Install **RootMyGalaxyUltra-1.2.19.apk** over the existing app; it uses the same package and release signing key.
2. If SusFS was activated with an earlier release, perform a **full reboot** first, then re-run SusFS activation so the updated module is loaded.

The bundled backends and boot helper are unchanged from 1.2.15. The boot helper does not need reinstalling for this update.
