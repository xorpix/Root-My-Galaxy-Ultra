## What's new

- **SusFS reliability and safety fixes:** fixes file-permission handling, mount and control races, redirected file opens, memory-map filtering and 32-bit file information. The rebuilt module passed automated checks and maintainer phone testing.
- **Clearer compatibility checks:** SusFS requires an exact supported firmware profile and reports missing hook coverage instead of accepting incomplete rules.
- **Settings correction:** “Built-in root payloads” now includes **KowSU**, alongside KernelSU, KernelSU-Next and BakaSU, in every supported language.

## Updating

1. Install **RootMyGalaxyUltra-1.3.4.apk** over the existing app using the same release signing key.
2. Perform a **full reboot** so the updated SusFS module can load. A soft reboot keeps the existing kernel modules in memory.
3. Activate root and enable SusFS again.

Use the manager matching your selected backend. Supported firmware profiles remain BZIG, BZID and BZJA; firmware updates still require a matching profile.
